# 0.0.2 — Native polish and llama icons

The first source-backed development release, before the LlamaBar rename.

- Native General/Models tabs, model profiles, CPU server controls, and bounded logs.
- Saved-draft protection, removal undo, explicit numeric validation, and accessibility labels.
- Custom llama menu bar glyph and llama-and-server launcher artwork.
- 17 tests passed in Swift and Xcode suites; light/dark and compact layouts inspected.

**Download:** `LlamaMenuBar-0.0.2-macOS-Intel.zip`. This historical archive contains `LlamaMenuBar.app`; 0.0.3 uses the LlamaBar name.

Requires an Intel Mac running macOS 13+, an externally installed compatible llama.cpp server, and a local single-file GGUF. CPU-only, one server. Ad-hoc signed development build; not notarized. See the wiki for the full changelog and remaining manual checks.

The matching source is tagged `v0.0.2`. Verify the archive with its accompanying SHA-256 file.
