# Instructions for AI contributors

These instructions apply throughout this repository.

## Required guidelines

- Before making changes, read and follow [AI Coding Guidelines.md](<AI Coding Guidelines.md>).
- Read [AI Coding Guidelines Sources.md](<AI Coding Guidelines Sources.md>) for the supporting references. Consult the linked sources when relevant to the change.
- Before designing or modifying UI, appearance, interactions, or accessibility, also read and follow [AI Coding UI Guidelines.md](<AI Coding UI Guidelines.md>) and review [AI Coding UI Guidelines Sources.md](<AI Coding UI Guidelines Sources.md>).
- Use the current repository versions of these documents. Keep these instructions as pointers rather than duplicating their rules.

## Verification

- Follow the verification requirements in the applicable guidelines. Use [docs/SETUP.md](docs/SETUP.md) for the project's build, test, and formatting commands.
- For UI changes, inspect the running app and verify relevant keyboard, screen reader, appearance, and supported macOS behaviors.
- In the completion report, describe what changed, what was verified, and any checks that could not be completed.
