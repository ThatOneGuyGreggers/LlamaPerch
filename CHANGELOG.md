# Changelog

## 0.0.2

- Add a llama-and-server launcher icon with all macOS icon sizes.

- Add a custom vector llama menu bar icon that adapts to system appearance.

- Apply Apple's design principles with native General/Models tabs and grouped forms.
- Add consistent status icons, loading progress, primary actions, and empty states.
- Keep unsaved drafts across Settings window closures; confirm discard on quit.
- Add model removal undo and explicit save/discard feedback.
- Replace ambiguous numeric fields with validated text input and bounded CPU steppers.
- Add accessibility labels, keyboard shortcuts, and light/dark layout verification.
- Preserve 0.0.1 settings compatibility and Intel/macOS 13 support.


## 0.0.1

- Native Intel macOS menu bar app with Settings and logs windows.
- Persistent named GGUF profiles, model selection, and explicit settings recovery.
- CPU-only, single-slot server start, stop/cancel, restart, and controlled switching.
- Bounded executable probes, health checks, log capture, and shutdown deadlines.
- Child socket ownership checks and cleanup before normal app quit.
- Native Xcode project, Swift package tests, and local build/format scripts.

This is a development build. Developer ID signing, notarization, and remaining manual acceptance checks are pending.
